Privacy Policy

Kebijakan Privasi (Privacy Policy)

Bagaimana kami mengelola, memproses, dan melindungi data Anda.

1. Pendahuluan

Ogah Lembur ("kami") menghormati privasi pengguna dan berkomitmen untuk melindungi data pribadi Anda. Kebijakan Privasi ini menjelaskan bagaimana aplikasi dan integrasi kami mengumpulkan, menggunakan, dan melindungi informasi saat Anda berinteraksi dengan layanan kami, termasuk integrasi API pihak ketiga seperti Meta (Facebook, Instagram, Threads) dan TikTok.

2. Data yang Kami Kumpulkan

Kami hanya mengumpulkan data yang benar-benar dibutuhkan untuk memfasilitasi fungsi otomasi dan publikasi konten:

  • Informasi Akun Publik: ID Pengguna dan nama pengguna media sosial yang Anda otorisasi secara sadar untuk integrasi penerbitan konten.
  • Token Akses (Access Tokens): Token otorisasi aman (OAuth) yang diterbitkan oleh platform resmi (TikTok/Meta) untuk mempublikasikan konten carousel/video atas izin Anda.
  • Konten yang Diterbitkan: Naskah, gambar, dan caption edukasi produktivitas kantor yang diproduksi untuk publikasi.

3. Penggunaan Informasi

Data yang dikumpulkan hanya digunakan untuk tujuan:

  • Menerbitkan konten edukasi ke akun media sosial yang telah Anda hubungkan (Direct Post / Photo Mode).
  • Mengambil analitik statistik umum performa konten (reach, likes, views) untuk pelaporan evaluasi internal.
  • Memastikan kestabilan koneksi integrasi API dan mencegah penyalahgunaan sistem.

4. Pembagian Data ke Pihak Ketiga

Kami tidak pernah menjual, menyewakan, atau memperdagangkan data pribadi Anda kepada pihak ketiga manapun. Data hanya dikirimkan ke server API resmi platform terkait (TikTok Open API, Meta Graph API) sesuai fungsi otorisasi yang Anda aktifkan.

5. Keamanan Data & Penyimpanan

Token akses dan kredensial sensitif disimpan secara terenkripsi di server internal dan tidak dapat diakses oleh publik. Anda berhak mencabut otorisasi akses aplikasi kami kapan saja melalui pengaturan keamanan akun TikTok atau Meta Anda.

6. Kontak Kami

Jika Anda memiliki pertanyaan tentang Kebijakan Privasi ini atau ingin mengajukan permohonan penghapusan data, silakan hubungi kami melalui email: ogahlembur.id@gmail.com.

Terms of Service

Ketentuan Layanan (Terms of Service)

Aturan dan ketentuan penggunaan layanan otomatisasi Ogah Lembur.

1. Penerimaan Ketentuan

Dengan menghubungkan akun media sosial Anda atau menggunakan sistem otomasi Ogah Lembur, Anda menyetujui untuk terikat oleh Ketentuan Layanan ini serta mematuhi pedoman komunitas platform terkait (TikTok Community Guidelines dan Meta Terms of Service).

2. Penggunaan yang Diperbolehkan

Layanan ini dirancang untuk otomasi penerbitan konten informatif seputar produktivitas kantor, trik AI, spreadsheet, dan tips kerja sehat. Anda setuju untuk tidak menggunakan layanan ini untuk:

  • Menyebarkan konten spam, penipuan, malware, atau materi berbahaya lainnya.
  • Melanggar hak cipta atau hak kekayaan intelektual pihak lain.
  • Melakukan tindakan yang melanggar hukum atau aturan platform penerbit.

3. Integrasi Pihak Ketiga & Tanggung Jawab

Layanan kami bergantung pada ketersediaan API pihak ketiga (TikTok API, Meta Graph API). Kami tidak bertanggung jawab atas pembatasan akun, kegagalan jaringan, atau perubahan kebijakan dari penyedia platform pihak ketiga.

4. Penghentian Layanan

Kami berhak menangguhkan atau menghentikan akses otomasi jika ditemukan indikasi pelanggaran terhadap ketentuan ini atau pedoman platform mitra.

5. Perubahan Ketentuan

Kami dapat memperbarui Ketentuan Layanan ini sewaktu-waktu. Perubahan akan berlaku segera setelah dipublikasikan pada halaman ini.
